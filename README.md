# 🧠 Antes de programar...

Quando receber um problema, não comece imediatamente escrevendo código.

Primeiro pergunte:

```text
🤔 Qual é o problema?

📥 Quais informações eu tenho?

📤 Qual resultado preciso obter?

🧩 Posso dividir o problema em partes menores?

📝 Quais passos preciso executar?

💻 Como posso transformar esses passos em código?
```

Essa forma de pensar será muito mais importante do que simplesmente decorar comandos.

# 💡 Uma regra importante

Durante esta UC você provavelmente verá várias vezes:

```text
ERRO
```

E está tudo bem. 😄

Na programação:

```text
Erro
 ↓
Investigar
 ↓
Entender
 ↓
Corrigir
 ↓
Testar novamente
 ↓
Aprender
```

Um código que não funcionou na primeira tentativa não significa o fim da atividade.

Significa que ainda existe um problema para investigar e resolver.

# 🤖 E a Inteligência Artificial?

Ferramentas de Inteligência Artificial podem ajudar durante o aprendizado, mas existe uma diferença importante entre:

```text
❌ pedir uma resposta pronta

e

✅ usar a IA para entender como resolver o problema
```

Use a tecnologia para **aprender**, não para pular o aprendizado.

Boas perguntas para fazer:

> "Explique por que meu código não funciona."

> "Me dê uma dica sem entregar a resposta."

> "Explique esse código passo a passo."

> "Crie um exercício parecido para eu praticar."

Assim, a IA se transforma em uma ferramenta de estudo.
