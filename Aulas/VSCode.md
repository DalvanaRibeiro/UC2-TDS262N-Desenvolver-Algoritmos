# 1. O que é o VS Code?

O **Visual Studio Code (VS Code)** é um editor de código desenvolvido pela Microsoft.

Ele é:

- gratuito;
- leve e rápido;
- disponível para Windows, Linux e macOS;
- compatível com diversas linguagens de programação.

---

# 2. Principais recursos

O VS Code oferece recursos que facilitam a programação:

- destaque de sintaxe;
- autocompletar código;
- suporte a JavaScript, Python, HTML, CSS, Java e outras linguagens;
- instalação de extensões;
- terminal integrado;
- integração com Git;
- execução e depuração de código.

---

# 3. VS Code para JavaScript

O VS Code possui suporte para **JavaScript** e ajuda durante o desenvolvimento com:

- sugestões de código;
- identificação de erros;
- organização dos arquivos;
- extensões que adicionam novas funcionalidades.

---

# 4. Abrindo um projeto

É recomendado criar uma pasta para organizar cada projeto.

No VS Code:

```text
File → Open Folder → Escolher a pasta
```

Exemplo:

```text
meuProjeto/
│
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── img/
```

---

# 5. Criando arquivos

Podemos criar arquivos utilizando o **Explorer** do VS Code.

Para JavaScript, utilizamos a extensão:

```text
.js
```

Exemplo:

```text
script.js
```

Dentro dele podemos escrever:

```javascript
console.log("Olá mundo!");
```

---

# 6. Terminal Integrado

O VS Code possui um terminal que permite executar comandos sem sair do editor.

Para abrir:

```text
Terminal → New Terminal
```

Atalho:

```text
Ctrl + `
```

---

# 7. Paleta de Comandos

A **Command Palette** permite pesquisar rapidamente comandos e funcionalidades.

Atalho:

```text
Ctrl + Shift + P
```

---

# 8. Extensões

As **extensões** adicionam novas funcionalidades ao VS Code.

Elas podem adicionar:

- suporte a linguagens;
- temas;
- depuradores;
- snippets;
- ferramentas para desenvolvimento.

Um exemplo apresentado é o **Live Server**, utilizado no desenvolvimento Web para facilitar a visualização das páginas no navegador.

---

# 9. Executar e Depurar

O VS Code possui ferramentas para **execução e depuração de código**.

Depurar ajuda a:

- encontrar erros;
- acompanhar a execução;
- verificar o comportamento do programa.

---

# 10. Dicas de Organização

Ao programar:

- organize arquivos e pastas;
- utilize nomes descritivos;
- evite espaços nos nomes;
- utilize comentários no código;
- anote comandos importantes;
- divida problemas grandes em pequenas tarefas.

Exemplos:

```text
meuProjeto
scriptPrincipal.js
styleBase.css
```

---

# 11. Consulta Rápida

| Recurso | Função |
|---|---|
| VS Code | Escrever e editar códigos |
| Explorer | Organizar arquivos e pastas |
| Terminal | Executar comandos |
| Extensions | Adicionar funcionalidades |
| Command Palette | Acessar comandos rapidamente |
| Debug | Auxiliar na identificação de erros |
| Git | Controle de versão |

# Para lembrar

```text
Criar pasta do projeto
        ↓
Abrir no VS Code
        ↓
Criar os arquivos
        ↓
Escrever o código
        ↓
Executar
        ↓
Testar e corrigir
```

> 💡 **Dica:** mantenha seus projetos organizados desde o início. Isso facilita encontrar arquivos, entender o código e corrigir problemas.
